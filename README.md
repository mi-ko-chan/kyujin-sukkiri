# 求人すっきり

DODA・エン転職・マイナビ転職の求人一覧で、選択した条件に一致する求人を非表示にするChrome／Microsoft Edge向け拡張機能です。

## 対応サイト

- DODA： https://doda.jp/
- エン転職： https://employment.en-japan.com/
- マイナビ転職： https://tenshoku.mynavi.jp/

各サイトの求人一覧ページで動作します。

## 主な機能

- 選択したワードを含む求人の非表示
- 勤務地が曖昧な求人の非表示
- 登録済み派遣会社の求人や、雇用形態に派遣と記載された求人の非表示
- フルリモート・完全在宅の求人の非表示
- フィルター全体のON／OFF
- 現在のページだけ一時的に全件表示
- 設定の自動保存

除外条件は、ブラウザの拡張機能アイコンから選択できます。
複数の条件を有効にすると、いずれかの条件に一致した求人を非表示にします。

**フルリモート・完全在宅の除外は、初期設定ではOFFです。**

## インストール方法（ZIP版）

1. このリポジトリの「Releases」を開きます。
2. 最新リリースの「Assets」から `kyujin-sukkiri-v0.6.1.zip` をダウンロードします。
   - `Source code (zip)` は選ばないでください。
3. ダウンロードしたZIPを解凍します。
4. ブラウザの拡張機能管理画面を開きます。
   - Chrome： `chrome://extensions/`
   - Microsoft Edge： `edge://extensions/`
5. 「デベロッパーモード」をONにします。
6. 「パッケージ化されていない拡張機能を読み込む」を押します。
7. 解凍したフォルダのうち、`manifest.json` が入っているフォルダを選択します。
8. すでに開いている求人一覧ページを再読み込みします。

読み込んだフォルダは、インストール後も削除・移動せずに保管してください。

## 使い方

1. 対応サイトで求人一覧ページを開きます。
2. ブラウザの拡張機能メニューから「求人すっきり」を開きます。
3. 非表示にしたい条件やワードを選択します。
4. 設定に一致した求人が非表示になります。

求人が消えすぎる場合は、除外条件を減らすか、一時的な全件表示をご利用ください。

## 判定について

求人一覧に表示された文章と、拡張機能内の企業リストを使って判定します。
求人の詳細ページを自動取得する機能はありません。

- 勤務地の除外を有効にすると、勤務地が省略されている求人や、具体的な勤務場所を確認できない求人も非表示になる場合があります。
- 派遣会社の除外は会社単位のため、登録企業の本社職なども非表示になります。
- 企業リストは、すべての派遣会社を網羅するものではありません。
- フルリモートの除外には、「フルリモート可」などの記載も含まれます。
- 選択したワードの記載状況によって、判定漏れや意図しない非表示が生じる場合があります。

求人の実際の雇用形態や勤務条件を確定するものではありません。応募前に求人内容をご確認ください。

## データの取り扱い

求人の判定はブラウザ内で行います。
設定はブラウザ内に保存し、求人情報や設定を外部サーバーへ送信しません。

アクセス解析や広告配信の機能はありません。

## ZIP版の更新方法

ZIP版には自動更新機能がありません。

1. 最新版の配布ZIPをダウンロードして解凍します。
2. 読み込み済みフォルダ内のファイルを、新版の内容で置き換えます。
3. ブラウザの拡張機能管理画面で「求人すっきり」の再読み込みボタンを押します。
4. 求人一覧ページも再読み込みします。

## 注意事項

- 求人サイトの表示変更により、正しく動作しなくなる場合があります。
- 非表示にしても、サイトに表示される検索結果件数やページ数は変わりません。
- 非表示にした求人の代わりに、別の求人を自動取得する機能はありません。
- 各求人サイトのスマートフォンアプリには適用されません。
- 本拡張機能は、各求人サイトの運営会社が提供・公認するものではありません。
