# 求人すっきり

DODA・エン転職・マイナビ転職の求人一覧で、希望に合わない求人を非表示にするブラウザ拡張機能です。Microsoft EdgeとGoogle Chromeに対応しています。

## インストール

### Microsoft Edge

以下のストアページからインストールしてください。

https://microsoftedge.microsoft.com/addons/detail/求人すっきり/llkichddjaabecpebicbdfmkkanflijm

1. Edgeで上記のページを開きます。
2. 「取得」または「インストール」を押します。
3. 確認画面で拡張機能を追加します。
4. 開いている求人一覧ページを再読み込みします。

### Google Chrome

以下から配布用ZIPをダウンロードしてください。

https://github.com/mi-ko-chan/kyujin-sukkiri/releases/download/v1.0.0/kyujin-sukkiri.zip

1. ダウンロードしたZIPを解凍します。
2. Chromeのアドレス欄に `chrome://extensions/` と入力して開きます。
3. 右上の「デベロッパーモード」をONにします。
4. 「パッケージ化されていない拡張機能を読み込む」を押します。
5. 解凍したフォルダのうち、`manifest.json` が入っているフォルダを選択します。
6. 開いている求人一覧ページを再読み込みします。

読み込んだフォルダは、インストール後も削除・移動せずに保管してください。ZIP版の更新は手動です。

## 主な機能

- 選択したワードを含む求人を非表示
- 勤務地が曖昧な求人を非表示
- 登録済み派遣会社の求人や、雇用形態に派遣と記載された求人を非表示
- フルリモート・完全在宅の求人を任意で非表示
- 非表示機能のON／OFF
- 現在のページだけ一時的に全件表示
- 設定の自動保存

除外条件は、ブラウザの拡張機能アイコンから選択できます。複数の条件を有効にすると、いずれかに一致する求人を非表示にします。

**フルリモート・完全在宅の除外は、初期設定ではOFFです。**

## 対応サイト

- DODA：https://doda.jp/
- エン転職：https://employment.en-japan.com/
- マイナビ転職：https://tenshoku.mynavi.jp/

各サイトの求人一覧ページで動作します。

## 使い方

1. 対応サイトの求人一覧ページを開きます。
2. ブラウザの拡張機能メニューから「求人すっきり」を開きます。
3. 非表示にしたい条件やワードを選択します。

設定は自動で保存されます。

求人が消えすぎる場合は、除外条件を減らしてください。一時的に全件表示することや、非表示機能全体をOFFにすることもできます。

## 判定について

求人一覧に表示された文章と、拡張機能内の企業リストを使って判定します。求人の詳細ページを自動取得する機能はありません。

- 勤務地の除外を有効にすると、勤務地が省略されている求人や、具体的な勤務場所を確認できない求人も非表示になる場合があります。
- 派遣会社の除外は会社単位のため、登録企業の本社職なども非表示になります。
- 企業リストは、すべての派遣会社を網羅するものではありません。
- フルリモートの除外には、「フルリモート可」などの記載も含まれます。
- 求人の記載内容によって、判定漏れや意図しない非表示が生じる場合があります。

求人の実際の雇用形態や勤務条件を確定するものではありません。応募前に求人内容をご確認ください。

## データの取り扱い

求人の判定はブラウザ内で行います。設定はブラウザ内に保存し、求人情報や設定を外部サーバーへ送信しません。

アクセス解析や広告配信の機能はありません。

## 注意事項

- 求人サイトの表示変更により、正しく動作しなくなる場合があります。
- 非表示にしても、サイトに表示される検索結果件数やページ数は変わりません。
- 非表示にした求人の代わりに、別の求人を自動取得する機能はありません。
- 各求人サイトのスマートフォンアプリには適用されません。
- 本拡張機能は、各求人サイトの運営会社が提供・公認するものではありません。

- 実際に起きたこと
